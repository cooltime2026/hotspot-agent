## 2. 형상·좌표 약속 (HTML v15와 동일)
- 판 12×12 mm, 원점 = 판 왼쪽 아래, 채널은 **y 방향**으로 흐름.
- 바닥판 z 0~0.1, 채널층 z 0.1~0.5. 채널 22개: 중심 x = 0.75 + 0.5·j (j=0..21), 폭 0.25, 피치 0.5, 높이 0.4 mm.
- M0·M계열(M1,M3,M4): 채널 y 1.5~10.5 + 헤더(y 0.5~1.5, 10.5~11.5). M5: 헤더 없음, 채널 y 1.5~10.5. D계열: 채널 y 0.6~11.4.
- 매니폴드층: 관통층(P 마스크) 위 덮개 홈층(U 마스크). 두께 M 0.15/0.4, D 0.5/0.35, D6 0.3/0.35. 덮개 0.15, 포트 지름 0.8 mm.
- 형상 키: M0 매니폴드 없음 / M1 중앙 집중 빗살 / M3 V자 빗살 / M4 핫스팟 직상부 공급 / M5 파도형 빗살 / D0 이중 바람개비 / D1 말굽 / D2 엇갈린 막대 / D4 흡입 바람개비 / D5 말굽 완충 / D6 가로 빗살.
- **바닥 칸 이름 `r_c`**: r = y 행(아래부터 1~4, 1행 = y 0~3), c = x 열(왼쪽부터 1~4). 칸 3×3 mm.
- STEP 11개: `out/step_html/<키>.step` (바디 fluid / solid, 바닥 16칸 면 분할, 단위 mm). 생성 코드 `geometry/build_html.py` (HTML 마스크 `geometry/src/designs.json`에서 추출). M5는 포트와 안 이어진 바깥 채널 4개를 고체로 채움. D1·D5는 유체 회로 2개(정상).
- 캡처 시점 판별: 포트 위치로 방향을 맞춤(와이어프레임은 화면 아래 = +y인 경우가 많았음, 45° 돌린 화면도 있었음).

## 6. 결정된 것 / 기각된 것
- 매니폴드: HTML 10종 + M0(사용자 선택). U/Z/트리형 계획은 폐기.
- 유속 5단계(위 표). 나노유체는 물로만 CFD, 물성식 보정(유량분배는 Re 상사로 환산 가능).
- PINN 비추천(느리고 부정확). 딥러닝은 데이터 많을 때만.
- OpenFOAM을 이 환경에서 돌리는 안: 설치 가능 확인(v1912). 사용자가 "어떻게 믿냐"고 해서 **신뢰 절차**를 제안함: ① 설정 먼저 공개·고정 ② D0/D1 압력 10개를 ±10% 재현 못하면 폐기 ③ 사용자가 결과를 숨긴 블라인드 테스트(예측 먼저 제출) ④ 질량보존·해석해 점검. **아직 사용자 승인 안 함.**

## 7. 지금 진행 중
- **M0 실행 시작**: 핫스팟 = 입구 쪽 가장자리 줄의 가로 두 칸(x 0~6). M0은 좌우 대칭이라 왼/오 무관.
  - HTML대로 입구 (3,1),(9,1)이면 **1_1 + 1_2**, 반대면 **4_1 + 4_2**. → 압력 캡처(높은 압력 포트 = 입구)로 확정할 것.
  - 사용자에게 요청한 것: 유속별 캡처(바닥 최고온도, 압력 최대, **채널 단면 속도 y=6**), 가능하면 속도 색상바 범위 고정(예: 0~0.6 m/s).
  - M0은 채널 중간 뚫림 없음 → y=6 한 장으로 유량분배 전체 길이 완성 가능.
