# 유량분배(관성) 학습 계획 (사용자 요청 2026-11-19)
- 목표: HTML 에이전트의 Navier-Stokes/관성 유량 풀이(flowSolve)를 머신러닝으로 대체. 출력 = 채널 22개의 y 방향 유량 F[j](y) (HTML d.T.F와 같은 의미, +y 양수).
- 측정: geometry/flow_probes.py → out/simscale/flow_probes/<키>_channel_probes.csv (채널 단면 3x3 가우스 점 × 0.5 mm 간격, 적분 오차 0.4%).
- 물성 상수·중력 0이면 유량분배는 열 조건과 무관 → 설계 × 유량마다 1회면 충분 (열 없는 유동 전용 해석 가능).
- 유량분배는 레이놀즈수만의 함수 → 나노유체는 Q_물환산 = Q·(ρ_nf/μ_nf)/(ρ_w/μ_w)로 같은 모델 사용 (유동 데이터 Re 범위 안에서만).
