# 핫스팟 에이전트 v23 (머신러닝 판) — 계산 방법 정리 (2026-11-28)

코드(html_v23/hotspot_agent_v23.html 의 주석과 식)에서 직접 확인한 내용. 계산식 자체는 원본 v23 그대로이고, 바꾼 것은 '후보 만들기·순위·순서'뿐.

## 1. 전체 순서
1. 핫스팟(위치·크기·열유속)과 운전 조건(유량, 입구 온도, 재질, 유체)을 받음
2. 후보 모양 만들기 (약 30~35개)
3. 후보마다 **간단 계산** → 1위(자동 최적화 모양)와 2~5위 정함
4. 1·2위만 **3D 계산**으로 다시 풂 → 더 시원한 쪽이 1위
5. (그 사이) 기존 구조 10개도 간단 계산으로 비교용 표시

## 2. 후보 모양
- 핫스팟에 맞춰 만든 모양: 원본 v23 규칙(바람개비형·V자 빗살형·대역 대향류형·흡입형 등 25개) + 머신러닝이 고른 규칙·띠·F 설계 + 머신러닝이 진화시킨 새 모양
- SimScale 로 돌려 본 모양(실측 모양): 머신러닝 점수 상위 5개
- 제작 검사(aCheck): 벽 0.2 mm 이상, 물길 연결, 포트 4개 위치

## 3. 간단 계산 (3~5위 값, 그리고 3D 가 끝나기 전의 1·2위 값)
두 단계.
- **유량 나누기(flowSolve)**: 매니폴드 2층(관통층·덮개 홈)과 채널 22개를 '저항 그물'로 보고, 각 채널에 물이 얼마나 가는지 풂.
  층류 마찰식 + 관성 보정 2개(입구 포트 제트의 정체압, 채널로 꺾여 들어갈 때의 손실). 유량·물성마다 다시 풂.
- **온도(evaluate)**: 채널 안 물은 1차원(흐르는 방향)으로, 고체(바닥·핀)는 띠별 전도로 놓고 함께 풂.
  열전달계수는 문헌 상관식(발달 구간 Nu: Lee & Garimella, 완전발달: Shah & London, 포트 아래 제트 충돌: Liu·Lienhard·Lombara).
  압력강하 = 그물 저항 + 포트·꺾임 손실.
- 걸리는 시간: 후보 하나에 1~6초.
- 유효 판정: 수렴, 에너지 수지 오차 1 % 미만, 물 온도 95 ℃ 이하(단상 범위). 벗어나면 '범위 밖'.

## 4. 3D 계산 (1·2위 값)
- **흐름**: 3D 정상상태 층류 나비에–스토크스 식을 격자에서 직접 풂(관성 항 포함, 생략 없음). SIMPLEC + 멀티그리드.
- **열**: 그 속도장 위에서 물(대류+전도)과 고체(전도)를 함께 푸는 켤레 열전달.
- 격자: 기본 0.05 mm, 채널 안은 0.025 mm(채널 폭 10칸·깊이 16칸). 유체 칸 수십만~백만 개.
- 경계: 입구 포트에 유량, 출구 포트 압력 0, 바닥에 열유속 지도, 나머지 단열.
- 결과 검사: 에너지 수지 ±2 %, 온도·압력이 물리적으로 맞는 범위.
- 걸리는 시간: 후보 하나에 약 30분(시험: 두 후보 46분, 4코어).

## 5. 간단 계산과 3D 계산의 차이
| | 간단 계산 | 3D 계산 |
|---|---|---|
| 방식 | 저항 그물 + 1차원 물 + 상관식 | 격자에서 식을 직접 풂 |
| 시간 | 몇 초 | 약 30분 |
| 쓰는 곳 | 모든 후보, 3~5위 표시 | 1·2위만 |
- 시험 한 번(기본 핫스팟 두 곳, 55 mL/min): 1위 간단 66.5 ℃·1.8 kPa → 3D 65.3 ℃·2.8 kPa / 2위 간단 78.7 ℃·2.0 kPa → 3D 75.1 ℃·4.5 kPa.
  즉 3D 가 온도는 1~4 ℃ 낮게, 압력강하는 1.5~2배 높게 나옴(이 한 번의 시험 기준).

## 6. 순위 규칙
- 1위 = 핫스팟에 맞춰 만든 모양 중: 한도(최고 온도·압력강하·Re 2300)를 지키는 것 우선 → 간단 계산 최고 온도가 가장 낮은 것 → 0.5 ℃ 이내면 압력강하 작은 쪽 (원본 v23 규칙)
- 2~5위 = 실측 모양, 간단 계산 온도 순
- 3D 뒤: 1·2위 중 3D 로 더 시원한 쪽이 1위

## 7. 머신러닝이 하는 일
- SimScale 239 Run 으로 학습한 칸별 온도 모델(릿지)로: ① 새 모양을 진화시켜 후보에 넣음 ② 실측 모양 중 어떤 5개를 계산해 볼지 고름.
- 최종 순위는 머신러닝 점수가 아니라 위의 계산이 정함.

## 8. 확인된 것 / 안 된 것
- 확인됨: 순서와 순위 규칙이 화면에서 그대로 동작(브라우저 시험), 3D 뒤 1·2위 카드가 3D 값으로 바뀜.
- 확인 안 됨: 간단 계산·3D 계산이 SimScale 과 얼마나 맞는지. 어긋난 예 — 2_1+2_2 에서 V자 빗살형(폭 0.4·간격 2)은 간단 계산 125.1 ℃, SimScale 실측 88.8 ℃.
